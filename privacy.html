Overview

Privacy Policy for MoonChat

MoonChat is a browser extension that provides token-specific chat room access for supported Solana-related websites. This Privacy Policy explains what data MoonChat processes, how it is used, how it is stored, and how it is shared.

Identity & Access

Pseudonymous Participation

MoonChat is designed to operate without requiring a real name, email address, or password. Users participate through a self-chosen username or nickname.

Data We Process

  • 01
    Username / Nickname

    We process the username or nickname you choose in order to identify your messages and user state inside MoonChat.

  • 02
    Chat Messages

    Chat messages sent through MoonChat are processed in order to display them in token-specific chat rooms and provide realtime chat functionality.

  • 03
    Token and Room Context

    MoonChat processes token addresses and related room identifiers so the extension can open the correct token-specific chat room.

  • 04
    Supported Page Context

    On supported websites, MoonChat may inspect the currently open token page and limited relevant page content to determine which token is being viewed and connect the user to the matching chat room.

  • 05
    Locally Stored Preferences

    The extension stores lightweight local state such as favorites, recently viewed rooms, username, and basic interface/session preferences in the browser.

How We Use Data

MoonChat uses processed data only to provide its core extension functionality, including:

  • opening the correct token-specific chat room
  • displaying and sending chat messages
  • showing trending rooms and favorites
  • providing realtime chat updates
  • maintaining local extension preferences and session-related state

Supported Websites

MoonChat currently supports token detection and room-opening flows on supported Solana-related websites, including:

  • pump.fun
  • gmgn.ai
  • axiom.trade
  • dexscreener.com

This functionality is limited to the user-facing feature of opening the matching MoonChat room for the token currently being viewed.

Local Storage

Certain data is stored locally in the browser to improve usability and speed, including:

  • username / nickname
  • favorites
  • recently viewed rooms
  • lightweight extension UI state
  • temporary room-opening state used by extension flows

Remote Code & Tracking

  • No Remote JavaScript MoonChat does not load or execute remote JavaScript.
  • No Advertising Use User data is not used for personalized advertising, credit scoring, lending decisions, or unrelated profiling.
  • No Invasive Tracking MoonChat does not use invasive third-party tracking systems to profile user behavior for advertising purposes.

Security

MoonChat uses secure network connections for backend and realtime communication.

Updates & Contact

We may update this Privacy Policy from time to time to reflect changes to MoonChat’s functionality, supported websites, or legal requirements.
